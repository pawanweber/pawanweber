## 🔐 How I Think About Code

Most developers ask — *does it work?*

I ask —

- 🔒 **Is it secure?** — every input validated, every route protected, every secret hidden
- ⚡ **Is it fast?** — cached where it should be, queries optimized, no N+1 problems hiding in the dark
- 🧹 **Is it clean?** — controllers that are 20 lines, not 800; logic that lives where it belongs
- 📦 **Does it scale?** — built for 10 users today and 10,000 users tomorrow
- 🤝 **Can the next developer read it?** — because code is read far more than it is written

That's the difference between code that ships and code that survives.
